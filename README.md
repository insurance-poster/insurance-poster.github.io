# 🏥 Insurance Sales Poster Builder

保险销售海报生成器 - 一键生成专业的保险产品展示海报

## Features

✨ **多语言支持** - 中文、English、Bahasa Malaysia、ไทย  
🎨 **即时预览** - 实时查看海报效果  
📄 **A4打印** - 支持在A4纸上并排打印（海报+医药卡）  
💳 **医药卡详情** - 完整的医药卡福利展示  
📱 **响应式设计** - 支持各种设备访问  

## 使用方法

1. 访问 https://insurance-poster.github.io/
2. 在左侧表单填入客户信息
3. 中间实时显示保险海报预览
4. 右侧显示医药卡详细信息
5. 按 Ctrl+P / Cmd+P 打印成PDF或A4纸

## 语言切换

点击右上角的语言按钮即可切换：
- 🇨🇳 中文
- 🇺🇸 English
- 🇲🇾 Bahasa
- 🇹🇭 ไทย
